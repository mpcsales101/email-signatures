Gmail

  1. Select Copy signature above.
  2. In Gmail, open Settings, then See all settings.
  3. Under Signature, select Create new, name it, and paste.
  4. Set it as the default for new emails and replies, then Save changes at the bottom.

Apple Mail (Mac)

  1. Open this file in Safari and select Copy signature.
  2. In Mail, open Settings, then Signatures.
  3. Choose your account, select +, name it, and paste into the right-hand box.
  4. Untick Always match my default message font.

iPhone and iPad

  1. Press and hold on the signature and copy it.
  2. Go to Settings, Apps, Mail, Signature, and paste.
  3. Shake to undo if iOS strips the styling.
